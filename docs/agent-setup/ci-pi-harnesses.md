# Constant Integration worker harnesses

Supervised worker bundles live under [harnesses/bonsai](https://github.com/xaime-vp/agent-and-skills/blob/a701dcf2de332cce285b49c0b7c609f2d75d4328/harnesses/bonsai/README.md), with one self-contained role directory and shared read-only helpers. Coder, test-specialist, documentation and reviewer each receive focused tools and a method skill. Native editing, shell and review restrictions still come from the sealed supervisor-selected profile.

These bundles are separate from developer-side `.pi/extensions/` and `.pi/skills/`. They do not change the root Git developer workflow, select live workers, add credentials or authorize publication. They are not loaded by ordinary workspace discovery.

The [release consumption contract](https://github.com/xaime-vp/agent-and-skills/blob/a701dcf2de332cce285b49c0b7c609f2d75d4328/harnesses/bonsai/README.md#release-consumption-contract) describes explicit selection, import closure, hashing, read-filetype compatibility and remaining product integration. Stage and inspect resources before any installation. Source support, exported assets, observed runtime activation and live task success are separate evidence.
